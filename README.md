# К столу

Личная книга рецептов. Статический сайт без сборки, зависимостей и сервера базы данных. Для GitHub Pages. Тексты взяты из сохранённых авторских описаний, фотографии — реальные кадры из видео. Исходные MP4 в сайт не входят.

## Открыть локально

Откройте `index.html` двойным щелчком или запустите `python -m http.server 8765 --bind 127.0.0.1` в этой папке и перейдите на http://127.0.0.1:8765. Для постоянного адреса на всех устройствах используйте GitHub Pages.

## Опубликовать через GitHub Desktop

1. File → Add local repository → выбрать **эту папку** `recipe-site`. Если репозитория ещё нет, выбрать **create a repository here**. Репозиторий должен находиться именно внутри `recipe-site`, а не в родительской папке с видео.
2. Создать коммит и выбрать Publish repository. Для GitHub Free нужен публичный репозиторий. В нём только сайт и фото; тексты рецептов станут публичными.
3. На GitHub: Settings → Pages → Source → **GitHub Actions**.
4. Во вкладке Actions дождаться задачи **Publish recipe book**. Если коммит был отправлен до включения Pages, открыть задачу и нажать Run workflow.
5. Постоянная ссылка появится в Settings → Pages и в выполненной задаче. Работает без своего домена и включённого компьютера.

## Что работает

- Поиск по названию, ингредиентам, тегам и авторскому тексту.
- Категории: завтрак, обед, ужин, выпечка, десерт, напитки. Один рецепт может быть в нескольких категориях.
- Фильтр по нескольким тегам (пересечение), избранное, таблица и сетка.
- Карточка с ингредиентами, шагами, исходным текстом и ссылкой на VK.
- Общий список покупок с разделением по блюдам и отметками купленного.
- Свои теги, категории, исправления ингредиентов и шагов, загрузка фото.
- Экспорт/импорт личных данных для переноса на другое устройство.

## Сохранение и ограничения

Правки, фотографии пользователя, избранное и отметки сохраняются в `localStorage` браузера. Автоматической синхронизации между телефоном и компьютером нет. Для переноса — настройки в шапке → резервная копия. Не очищайте данные сайта без резервной копии. Исходная база одинакова на всех устройствах; чтобы обновить её для всех, измените `recipes.js` и отправьте коммит.

У пяти рецептов нет исходного текста. У двух нет фотографий, поскольку публикация содержала только текст и фото, которые не были скачаны. В этих карточках можно добавить своё фото. У некоторых авторов отсутствуют шаги, количества или единицы — невыясненные значения не выдумывались. Кадр видео может содержать процесс приготовления или надписи автора, его можно заменить.

## Обновить коллекцию из локальных файлов

`python tools/build_library.py` из этой папки. Требуются оригинальные папки рецептов на уровень выше, Python, FFmpeg/ffprobe. После редакторской правки `recipes.js` не запускайте импорт заново без сохранения правок: он пересобирает базу. Для работы опубликованного сайта Python и FFmpeg не нужны.
